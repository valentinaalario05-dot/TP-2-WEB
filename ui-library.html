Component
Información

Tres componentes para presentar contenido informativo: FAQ con acordeón nativo para preguntas frecuentes, Module Explorer Nav para navegar y expandir módulos del curso, y Erg Left para recorrer ítems ergonómicos con flechas y click.

¿Necesito experiencia previa con telemetría?

No. El curso arranca desde cero y te enseña a leer los datos paso a paso. Solo necesitás tener el simulador instalado.

¿Las sesiones son individuales o grupales?

Individuales. Cada sesión está diseñada específicamente para tu nivel y tus objetivos.

¿Obtengo un certificado al finalizar?

Sí, recibís un certificado digital de Apex Sim Racing al completar todos los módulos.

  • POSICIÓN

    Una postura correcta aumenta el control y la consistencia durante toda la sesión.

  • VISIÓN

    La distancia y el campo visual correctos mejoran la percepción de velocidad, frenadas y referencias.

  • CONTROLES

    Configuramos volante, pedales y force feedback para transmitir información precisa.

  • PRECISIÓN

    Un simulador correctamente calibrado genera datos confiables para entrenar.
