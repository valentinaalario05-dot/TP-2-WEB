  QUÉ SE AGREGA EN home.html <style>
  (overrides específicos no cubiertos)
──────────────────────────────────────────────

@media (max-width: 768px) {

  /* Tipografía */
  body { font-size: 1rem; }
  p    { font-size: 1rem; }

  /* section-title: el clamp original (4rem, 6vw, 3.25rem) tiene
     min > max → siempre queda en 4rem. Se corrige en mobile. */
  .section-title { font-size: clamp(1.75rem, 8vw, 3rem); }

  /* <br> decorativos en subtítulos → flujo natural */
  .method-header__sub br,
  .perf-videos-subtitle br,
  #setup > .wrap > p br,
  .section-subtitle br { display: none; }

  /* Analytics: SVG 952×480 desborda → scroll horizontal */
  .analytics-dash { overflow-x: auto; -webkit-overflow-scrolling: touch; }
  #dashboard-svg  { min-width: 680px; }

  /* Coaches: 2 cols → 1 col */
  .coach-grid { grid-template-columns: 1fr; }

  /* Testimonios: 4 cols → 1 col */
  .review-grid { grid-template-columns: 1fr; }

  /* Sección "Del Simulador a la Pista":
     tiene aspect-ratio:2752/1047 inline → deja la sección en 143px. */
  .section[style*="aspect-ratio"] {
    aspect-ratio: auto !important;
    min-height: 320px;
    background-size: cover !important;
    background-position: center right !important;
  }

  /* Footer: columnas se apilan */
  .footer__top { flex-direction: column; }

  /* method-header subtitle: no cortar con max-width */
  .method-header__sub { max-width: 100% !important; }
}

──────────────────────────────────────────────
  REGLAS DE TRABAJO

1. Trabajar SOLO en home.html (no tocar index.html durante desarrollo)
2. Solo agregar dentro de @media (max-width: 768px)
3. No modificar HTML salvo casos críticos

10. Si algo se rompe en desktop después de editar mobile → revisar
    que @media (min-width: 769px) lo restaure
